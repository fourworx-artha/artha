## Decisions made
- **Checklist device row is per child** (the spec showed one child) — each child's device claim is checked individually; chore logged/approved are family-level firsts.
- **Checklist hides when ANY child has a settled payslip** (family-level, matching "shown until first settled payslip").
- **Bonus hint suppressed when an active bonus chore already exists** — the hint is pointless once the feature is in use; dismissal is permanent per device, not per day.
- **Child card hides while a draft is pending** — prevents "your first payday is Saturday" showing next to "new payslip ready" on payday.
- **Payday display uses the day name from `config.paydayDow`** — guided-period families are always weekly (D16), so no date math/month edge cases.
- **`SavingsGrowthChart` requires 2 actual points** — projection-only renders were flat zero lines for new families.
