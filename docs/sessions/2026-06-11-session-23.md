## Decisions made

- `round5pct(salary)` = `Math.max(5, Math.round(salary * 0.05 / 5) * 5)` — rent set to 5% of salary, rounded to nearest ₹5, minimum ₹5
- Currency auto-detected from `navigator.language` country code; user told "Change currency in settings after setup" (no in-flow currency picker for now)
- Chores created for `children[0]` only during onboarding; additional children's chores added post-setup via ChoreManager
- Mock payslip uses real `PayslipCard`; shows INR formatting (useCurrency falls back to DEFAULT_CONFIG.currency = 'INR' before family exists) — acceptable for Phase A
- `onComplete(createdResult)` called from "Go to Dashboard →" on handoff screen, not from the creation step — allows parent to linger on invite code screen
